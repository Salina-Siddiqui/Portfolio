# UI/UX Designer Portfolio

## Goal
Create a polished one-page personal portfolio inspired by Luma Infotech’s airy, editorial presentation without copying its content.

## Build
- Create a floating navigation bar with smooth links to Work, About, Services, and Contact.
- Build a bold introduction using Praise for expressive display text and Manrope for clear supporting copy.
- Add three visual case studies with generated product mockups, project roles, and outcomes.
- Add an About section, services list, design approach, client quote, and a strong contact area.
- Add subtle scroll reveals, hover motion, and a custom cursor on pointer devices while respecting reduced-motion settings.
- Make the page responsive and accessible across phones and desktop screens.

## Visual Direction
- Bright editorial canvas with charcoal typography, cyan as the main accent, and restrained coral/yellow supporting accents.
- Large-scale type, generous whitespace, crisp borders, and lightly layered surfaces.
- Adapt the reference’s premium agency rhythm while making the content clearly personal and portfolio-focused.

## Technical Details
- Use the existing TanStack Start and Tailwind setup.
- Define all colors, type, shadows, and motion as semantic design tokens.
- Load Praise and Manrope through document links.
- Add unique page metadata and verify the finished page in desktop and mobile-sized views.
